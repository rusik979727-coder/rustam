# Анимация: грыжа межпозвонкового диска (рабочий пример)

Проверенный пример полного цикла навыка: от раскадровки до MP4. Создан 15.11.2026. Готовое видео лежит в репозитории: `hernia-motion/out/hernia.mp4`. В этот пакет оно не входит, чтобы пакет оставался лёгким.

**Результат:** 26,67 с, 1920×1080, 60 fps, H.264 yuv420p, AAC 48 кГц, −17,6 LUFS, 1600 кадров. Шаг 1/60 с проверен по pts.

## Что здесь можно переиспользовать

| Файл | Приём |
|---|---|
| `scene.html` | Детерминированный `renderFrame(i)` (t = i/60), камера на сплайне Catmull-Rom (без остановок скорости на ключах). Ортографическая 3D-проекция призм: стенки по граням с отсечением невидимых и ламбертовым светом, крышки, наклон камеры от бокового вида к осевому. Motion blur из субкадров с адаптивным числом выборок по экранной скорости камеры. DOF слоями (deep / focus / upper) с маской глубины. Радиальный blur на ударах. Выноски, привязанные к проекции якоря. Подписи по словам с маской. Индикатор глав в экранных координатах. Зерно и виньетка. Предпросмотр: `?play` или `?t=сек`. |
| `audio.js` | Офлайн-музыка и SFX через `OfflineAudioContext`: пэд, бас, «пиано» из гармоник, сердцебиение, свисты, треск, гель, разряды, свёрточный ревербератор. События на тактовой сетке 90 BPM совпадают с визуальными акцентами. Нормализация, затем экспорт в WAV. |
| `render.mjs` | Локальный HTTP-сервер (шрифты не грузятся с `file://`), Playwright, 4 воркера, PNG-кадры, `stills`, `audio`. |
| `storyboard.md` | Варианты по сценам с выбором, карточки планов, главный риск и проба. |

## Сборка

```bash
npm i && node render.mjs audio && node render.mjs frames
ffmpeg -framerate 60 -i frames/f_%05d.png -i out/audio.wav \
  -af "volume=4dB,alimiter=limit=0.89:level=false" \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -r 60 \
  -c:a aac -b:a 256k -ar 48000 -movflags +faststart out/hernia.mp4
```

Рендер занимает около 3,5 мин на 4 ядрах (≈0,13–0,2 с на кадр).

## Уроки итерации (что нашла проверка экспорта)

- Проба по стоп-кадрам выявила такие дефекты: корпус позвонка выглядел трубой (лечится «талией» из трёх призм), «ступеньки» на экструзии плоской формы (лечится плотными слоями со stroke), вертикальные трубки при виде сверху читались как столбы (лечится маской затухания по глубине).
- Анализ RMS звука показал провал до −46 dB под титулом. Его заполнили нарастанием к удару. Громкость подняли с −21 до −17,6 LUFS лимитером при сведении.
- Плотная серия кадров декодированного MP4 на наклоне камеры показала двойника: одновременно были видны боковая и осевая проекции отростков. Боковую форму нужно гасить раньше (sinφ 0,10→0,40).
- Финальный заголовок пересекался с объектом. Камеру сдвинули по ключу, а не уменьшили текст.
- Честный статус: параметры, кадры и синхроточки проверены измерениями. Движение и звук на слух агент не оценивал.

## Ассеты

Шрифты Unbounded и Manrope (SIL OFL 1.1, @fontsource). Графика и звук созданы кодом. Медицинские утверждения ограничены базовыми фактами, в финале стоит дисклеймер.
