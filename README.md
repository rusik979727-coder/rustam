# Клиника кассасы

Пациенттердің консультация және ем үшін төлемдерін, клиника расходын (дәрі-дәрмек, жалақы, аренда т.б.) жазатын, **интернетсіз** жұмыс істейтін iPhone қосымшасы (PWA).

Қосымша `docs/` папкасында. Деректер тек телефонның өзінде сақталады, ешқайда жіберілмейді.

## iPhone-ға орнату

1. Safari-де қосымшаның сілтемесін ашыңыз (GitHub Pages мекенжайы).
2. Төмендегі **Бөлісу** батырмасын басып, **«Добавить на экран „Домой“»** таңдаңыз.
3. Негізгі экраннан «Касса» белгішесімен ашыңыз. Бір рет ашылғаннан кейін интернетсіз де жұмыс істейді.

## Сақтық көшірме

Аптасына бір рет **«Сақтық көшірме жасау»** батырмасын басып, `.json` файлды iCloud Drive-қа немесе WhatsApp-қа сақтаңыз. Жаңа телефонда **«Көшірмеден қалпына келтіру»** арқылы деректерді қайтарасыз.
