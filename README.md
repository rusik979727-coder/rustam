# Белес маркетинг — кестеге қосылған бағдарлама

**[«Маркетинг приложение»](https://docs.google.com/spreadsheets/d/1nVmHYM9AfG45Q_L5NDz8CFHa8dogqU3CB0hwvbZGJgk/edit)** кестесіне тікелей жазатын веб-бағдарлама.
Кесте «Белес маркетинг» кестесінің көшірмесі: құрылымы сол, ескі сандар тазаланған, бағдарлама **23.11.2026** күнінен басталады
(мамандар бұдан бұрынғы күндерге жаза алмайды; бастау күні `Code.gs` ішіндегі `START_DATE`). «Доступ» парағы кілттерімен бірге дайын тұр.
Код: [`apps-script/`](apps-script/) — `Code.gs` (сервер), `Index.html` (интерфейс), `appsscript.json` (баптау).

## Не істейді

| Кім | Не көреді / не енгізеді |
|---|---|
| **Таргетолог** | Күн сайын: лид саны, жұмсалған сома. Бір лид бағасы автоматты есептеледі. |
| **Колл-центр** | Сол күнгі **таргет лидтері автоматты көрінеді** және «Жаңа лидтер» өрісіне өзі толады. Енгізеді: запись, недозвон, в работе, отказ. Конверсия автоматты. Лидтер толық бөлінбесе — ескерту шығады. |
| **Ресепшн** | Өз блогына бөлек жазады: консультация, келді, сатып алды, ойланып жүр, отказ, нал / безнал / перевод. Жалпы касса автоматты. |
| **Бастық** | Барлығына доступ: айлық жалпы есеп (таргет → колл-центр → ресепшн → касса воронкасы, бір сатылым бағасы, орташа чек), күндер бойынша кесте, кез келген блокты түзету, өзгерістер журналы, барлық мамандардың сілтемелері. |

- Әр қызметкердің **«📈 Менің аналитикам»** бөлімі бар: өз көрсеткіштері өткен аймен салыстырылып, графиктер, апта күндері, үздік күндер және кеңестер көрсетіледі. Колл-центр өз конверсиясын команда орташасымен салыстырады, таргетолог өз лидтерінің жазылу мен сатылымға айналғанын көреді. Бастық кез келген қызметкердің аналитикасын таңдап ашады.
- Интерфейс екі тілде: **ҚАЗ / РУС** (жоғарғы оң жақтағы батырма).
- Барлық мәлімет **бір кестеге** — қазіргі «НОЯБРЬ» парағына, сол жолдар мен бағандарға жазылады (1-күн = B бағаны).
- Әр маманның **жеке сілтемесі** бар; маман тек өз блогын көреді және өзгертеді. Мамандарға кестенің өзіне доступ беру қажет емес.
- Жаңа ай басталғанда (мысалы, ДЕКАБРЬ) бірінші енгізуде парақ алдыңғы айдың үлгісімен **автоматты жасалады**.
- Кім, қашан, нені өзгерткені «Журнал» парағына жазылады.
- Кестеге жаңа блок қоссаңыз (мысалы «Колл-центр Сабина» сияқты), бағдарлама оны А бағанындағы атауынан («Таргет…», «Колл-центр…», «Ресепшн…») өзі табады. Атауы қайталанса, екіншісі `Ресепшн#2` деп аталады.

## Орнату (1 рет, ~5 минут)

1. [«Маркетинг приложение»](https://docs.google.com/spreadsheets/d/1nVmHYM9AfG45Q_L5NDz8CFHa8dogqU3CB0hwvbZGJgk/edit) кестесін ашыңыз → **Кеңейтімдер (Extensions) → Apps Script**.
2. `Code.gs` файлының ішін өшіріп, осы репозиторийдегі [`apps-script/Code.gs`](apps-script/Code.gs) мазмұнын қойыңыз.
3. **+ → HTML** басып, файлды `Index` деп атаңыз да, [`apps-script/Index.html`](apps-script/Index.html) мазмұнын қойыңыз.
4. (Міндетті емес) **Project Settings → Show "appsscript.json"** қосып, [`apps-script/appsscript.json`](apps-script/appsscript.json) мазмұнын қойыңыз (уақыт белдеуі — Алматы).
5. Сақтаңыз (💾), функциялар тізімінен **`setup`** таңдап **Run** басыңыз → Google рұқсат сұрайды → рұқсат беріңіз
   («Google hasn't verified this app» шықса: Advanced → Go to … (unsafe) → Allow — бұл сіздің өз скриптіңіз).
   «Доступ» парағы дайын тұр, кілттер өзгермейді.
6. **Deploy → New deployment → Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
   → **Deploy**.
7. Кестені жаңартыңыз (F5) → мәзірде **«Белес бағдарлама» → «2. Сілтемелерді жаңарту»**.
   «Доступ» парағының **«Сілтеме»** бағанында әр маманның жеке сілтемесі шығады.
8. Бастыққа «Бастық» жолындағы сілтемені, әр маманға өз сілтемесін жіберіңіз.

### «Доступ» парағы

| Аты-жөні | Рөлі | Кілт | Блок | Байланысқан таргет блогы | Сілтеме |
|---|---|---|---|---|---|
| Бастық | boss | … | | | … |
| Таргетолог | target | … | Таргет | | … |
| Айгерім | callcenter | … | Колл-центр | Таргет | … |
| Сабина | callcenter | … | Колл-центр Сабина | Таргет | … |
| Ресепшн | reception | … | Ресепшн | | … |

- **Жаңа маман қосу:** жаңа жол қосып, рөлі мен блогын жазыңыз, кілтке кез келген ұзын кездейсоқ мәтін жазыңыз → «Сілтемелерді жаңарту».
- **Сілтемені жабу:** кілтті өзгертіңіз немесе жолды өшіріңіз — ескі сілтеме бірден жұмыс істемей қалады.
- Рөлдер: `boss`, `target`, `callcenter`, `reception`.

### Кодты жаңартқанда

Apps Script-те кодты ауыстырғаннан кейін **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.
Сілтемелер өзгермейді.
