# Белес — менеджерлерге арналған өтінімдер жүйесі

Белес клиникасының (омыртқа грыжасы, протрузия, артроз, артрит) менеджерлеріне арналған жүйе. Ол үш жұмысты атқарады:
1. барлық көздерден келген өтінімдерді **бір жерге жинайды**;
2. өтінімдерді **менеджерлерге бөледі**;
3. **воронканы** жүргізеді.

Басты пайдаланушы — **бас менеджер**: ол бүкіл команданы бір экраннан бақылайды. Интерфейс: **қазақша / орысша**.

Жүйеде пациенттің ЖСН-і, диагнозы, медициналық картасы мен файлдары **сақталмайды**. Тек аты, телефоны және шағымының түрі сақталады.

## Мүмкіндіктер

| Бөлім | Не істейді |
|---|---|
| **Өтінімдер** | Kanban воронка (WhatsApp тізімдеріне сәйкес): Лид → Обработка → Не отвечает → Конс → Келді → Емге төледі / Отказ / Басылып кетті. «Бүгінгі лид» сүзгісі. Әр өтінімде: дереккөз, шағым, тарих (қоңырау / хабарлама / жазба), келесі хабарласу уақыты, **конс күні**, **сома** |
| **WhatsApp** | Барлық чат бір жерде, менеджер CRM-нен жауап жазады. Жеткізу статусы, оқылмағандар, «жауап күтуде» сүзгісі |
| **Менің күнім** (менеджер) | Бүгін хабарласатындар, тапсырмалар, бүгін/ертең конс, жеке жоспар |
| **Бас менеджер панелі** | Бүгінгі жағдай, жауапсыз өтінімдер (>15 мин), команда KPI (лид, конс, төледі, конверсия, жауап уақыты, түсім, мерзімі өткен тапсырма), жоспар/факт, воронка, дереккөздер, шағымдар, бас тарту себептері, тағайындалмаған өтінімдер + автобөлу, Excel экспорт |
| **Тапсырмалар** | Қолмен және автоматты тапсырмалар |
| **Баптаулар** | Менеджерлер, айлық жоспар, интеграция күйі |
| **Журнал** | Кім не өзгертті |

**Рөлдер:**
- `HEAD_MANAGER` (бас менеджер) бәрін көреді, өтінімдерді бөледі не ауыстырады, есептер мен баптауларға қол жеткізеді.
- `MANAGER` (менеджер) тек өз өтінімдері мен чаттарын көреді.

## Өтінімдер қайдан келеді
- **WhatsApp:** клиент жазса, өтінім өздігінен ашылады (Meta Cloud API).
- **Instagram Direct:** Meta webhook арқылы.
- **Сайт, Tilda, 2GIS формалары:** `POST /api/webhooks/lead?source=SITE`, тақырыбы `X-Webhook-Secret`.
- **Қоңырау, ұсыныс:** менеджер өтінімді қолмен енгізеді.

Бір нөмірден қайта жазса, жаңа өтінім ашылмайды, бар өтінімге тіркеледі. Бұрын жабылған өтінімі болса, «қайталама клиент» деп белгіленеді.

## Автоматтандыру
| Не | Қалай |
|---|---|
| Автобөлу | Жаңа өтінім менеджерлерге кезекпен (round-robin) беріледі |
| Эскалация | 15 минутта жауап болмаса, бас менеджерге тапсырма және Telegram хабарлама жіберіледі |
| «Не отвечает» | 2 сағаттан кейін қайта қоңырау шалу автоматты жоспарланады |
| Конс-қа жазу | Конс күні қойылғанда статус «Конс» болады. Клиент жақында жазған болса, тегін растау сұралады |
| Конс туралы еске салу | 24 сағат бұрын (`REMINDER_HOURS`). Тегін терезе ашық болса, тегін мәтін кетеді. Клиент «1» деп растаса, ештеңе жіберілмейді. Тек расталмаса және терезе жабық болса, бір ақылы үлгі хабарлама жіберіледі. Конс күні 2 сағат бұрын тек тегін болса ғана жіберіледі |
| Клиент жауабы | «1» → конс расталады және тегін «рахмет» жауабы кетеді. «2» → менеджерге «уақытын ауыстыру» тапсырмасы түседі |
| Конс өтті | Уақыты өтсе, бірақ статусы әлі «Конс» болса, менеджерге «келді ме?» деген тапсырма түседі |
| Қайта хабарласу | «Келесі хабарласу» уақыты келгенде тапсырма түседі |
| Күнделікті есеп | Әр кеш 20:00-де бас менеджерге Telegram арқылы жіберіледі: өтінімдер, конс, төлегендер, түсім, жоспар %, менеджерлер рейтингі |

Автоматтандыруды іске қосудың екі жолы бар:
- **Өз серверіңізде:** `npm run cron` (Docker-де ол өзі іске қосылады).
- **Сыртқы планировщик:** `GET /api/cron?job=frequent` (әр 5 минут) және `GET /api/cron?job=daily` (20:00). Сұрауға `Authorization: Bearer CRON_SECRET` тақырыбы қосылады.

## WhatsApp (ресми Cloud API)
- **Тегін 24 сағаттық терезе:** клиент жазғаннан кейін 24 сағат бойы еркін жауап беру тегін. Терезе жабылса, чатта тек «Үлгі жіберу (ақылы)» немесе «Телефоннан жазу» батырмалары қалады.
- **Ақылы хабарлар саны** бас менеджер панелінде, «WhatsApp» бөлімінде және Telegram есебінде көрінеді.

**Қосу қадамдары:**
1. business.facebook.com сайтында Meta Business аккаунтын ашып, компанияны растаңыз.
2. developers.facebook.com сайтында App құрып, WhatsApp өнімін қосып, нөмір тіркеңіз.
3. Webhook баптаңыз: `https://<домен>/api/webhooks/whatsapp`, Verify token = `WA_VERIFY_TOKEN`, `messages` жазылымы.
4. `.env` файлына жазыңыз: `WA_TOKEN`, `WA_PHONE_NUMBER_ID`, `WA_VERIFY_TOKEN`, `META_APP_SECRET`.
5. WhatsApp Manager → Message templates бөлімінде «Utility» санатымен екі үлгі жасап, бекітуге жіберіңіз:
   - `appointment_reminder` (kk): «Сәлеметсіз бе, {{1}}! Белес клиникасында {{2}} консультацияңыз бар. Растау үшін 1, ауыстыру үшін 2 жіберіңіз.»
   - `client_followup` (kk): «Сәлеметсіз бе, {{1}}! Белес клиникасынан жазып тұрмыз. Ыңғайлы болса, осы чатқа жауап беріңіз.»

## Қауіпсіздік
- **Құпиясөздер:** bcrypt арқылы сақталады, кемінде 8 таңба. 15 минутта 5 сәтсіз әрекет болса, логин бұғатталады.
- **Сессия:** httpOnly cookie, 12 сағат жарамды. Құпиясөз, рөл не белсенділік өзгерсе, ескі сессиялар жабылады.
- **`AUTH_SECRET`:** міндетті, кемінде 32 таңба. Продакшнда жоқ болса, жүйе іске қосылмайды.
- **Webhook-тер:** Meta қолтаңбасы (`META_APP_SECRET`) немесе құпия кілт арқылы тексеріледі.
- **Excel экспорты:** формула шабуылынан қорғалған.
- **HTTP тақырыптары:** CSP, X-Frame-Options, nosniff, HSTS.
- **Журнал:** өзгерістер, экспорт және сәтсіз логиндер жазылады.

## Іске қосу

**Компьютерде көріп шығу (әзірлеу режимі):**
```bash
npm install
cp .env.example .env          # AUTH_SECRET өзгертіңіз
npx prisma db push
npm run seed                  # демо-деректер (міндетті емес)
npm run dev                   # http://localhost:3000
```
Демо логиндер (құпиясөз `beles123`): `head` — бас менеджер; `aigerim`, `dana`, `erlan` — менеджерлер.

**Серверге орнату:** [DEPLOY.md](DEPLOY.md) нұсқаулығын қараңыз. Docker, PostgreSQL, автоматты HTTPS және күнделікті шифрланған резерв көшірме бір командамен орнатылады.
