# Белес CRM

Белес клиникасына (омыртқа грыжасы, протрузия, артроз, артрит) арналған CRM.
Негізгі пайдаланушы — **бас менеджер**: бүкіл команданы, өтінімдерді, кестені және түсімді бір экраннан бақылайды.
Интерфейс: **қазақша / орысша**.

## Мүмкіндіктер

| Бөлім | Не істейді |
|---|---|
| **Басқару панелі** (бас менеджер) | Бүгінгі жағдай, жауапсыз өтінімдер (>15 мин), команда KPI (лид, жазылу, конверсия, жауап уақыты, түсім, мерзімі өткен тапсырма), жоспар/факт, воронка, дереккөздер, бас тарту себептері, қарыздар, тағайындалмаған өтінімдер + автобөлу, Excel экспорт |
| **Менің күнім** (менеджер/дәрігер) | Бүгін хабарласатындар, тапсырмалар, бүгінгі қабылдаулар, жеке жоспар |
| **Өтінімдер** | Kanban воронка WhatsApp тізімдеріне сәйкес: Лид → Обработка → Не отвечает → Конс → Келді → Емге төледі / Отказ / Басылып кетті (қате/спам — есептерге кірмейді). «Бүгінгі лид» сүзгісі. «Не отвечает» қойылса — 2 сағаттан кейін қайта қоңырау автоматты жоспарланады. Дереккөз, шағым, тарих (қоңырау/хабарлама/жазба), келесі хабарласу күні, пациентке айналдыру |
| **Пациенттер** | Аты-жөні, ЖСН, телефон, диагноз, МРТ, қарыз; ем курстары (10 сеанс т.б.), медициналық карта (дәрігер жазбалары), файлдар (МРТ қорытындысы) |
| **Кесте** | Дәрігерлер бойынша күндік кесте, жазу, уақыт қақтығысын тексеру, статустар (жазылды/расталды/келді/келмеді/болдырмады) |
| **Касса** | Төлемдер (Kaspi/қолма-қол/карта/аударым), тәсіл бойынша қорытынды, қарыздар |
| **Тапсырмалар** | Қолмен және автоматты тапсырмалар |
| **Баптаулар** | Қызметкерлер мен рөлдер, дәрігерлер, қызметтер мен прайс, айлық жоспар, интеграция күйі |
| **Журнал** | Кім не өзгертті |

### Рөлдер
- `HEAD_MANAGER` — бәрін көреді, өтінімдерді бөледі/ауыстырады, есептер, баптаулар, экспорт.
- `MANAGER` — тек өз өтінімдері; пациенттер, кесте, касса.
- `DOCTOR` — өз кестесі, өз пациенттері, медициналық карта (қаржысыз).

## Автоматтандыру

| Не | Қалай |
|---|---|
| Өтінімдер өздігінен түседі | `POST /api/webhooks/lead?secret=…&source=SITE` (сайт, Tilda, 2GIS формалары), `/api/webhooks/whatsapp`, `/api/webhooks/instagram` (Meta). Бір нөмірден қайта жазса — жаңа өтінім ашылмай, барына тіркеледі |
| Автобөлу | Жаңа өтінім кезекпен (round-robin) менеджерге беріледі |
| Эскалация | 15 минутта жауап болмаса → бас менеджерге тапсырма + Telegram |
| Еске салу | Қабылдаудан 24 сағат және 2 сағат бұрын WhatsApp/SMS. Пациент «1» деп жауап берсе — статус «Расталды», «2» — менеджерге «ауыстыру» тапсырмасы |
| Автотапсырмалар | Келмеді → қайта жазу; курста 2 сеанс қалды → жалғастыруды ұсыну; курстан 30 күн өтті → жағдайын сұрау; келесі хабарласу уақыты келді → қоңырау |
| Күнделікті есеп | Әр кеш 20:00 — Telegram-ға бас менеджерге: лидтер, қабылдау, түсім, жоспар %, менеджерлер рейтингі |

Іске қосу тәсілдері (біреуін таңдаңыз):
- өз серверіңізде: `npm run cron` (әр 5 минут + 20:00);
- сыртқы планировщик (cron-job.org, Vercel Cron): `GET /api/cron?job=frequent` әр 5 минут, `GET /api/cron?job=daily` 20:00, `Authorization: Bearer CRON_SECRET`.

Кілттер `.env` ішінде (`.env.example` қараңыз). Кілт жоқ болса — сол арна өшірулі, жүйе бәрібір жұмыс істейді.

## Іске қосу

```bash
npm install
cp .env.example .env          # AUTH_SECRET өзгертіңіз
npx prisma db push            # дерекқор құру
npm run seed                  # демо-деректер (міндетті емес)
npm run dev                   # http://localhost:3000
```

Демо логиндер (құпиясөз `beles123`): `head` — бас менеджер, `aigerim`, `dana`, `erlan` — менеджерлер, `doctor` — дәрігер.
**Продакшнда** демо-деректерді жүктемеңіз немесе құпиясөздерді Баптаулар бөлімінде ауыстырыңыз.

**Серверге орнату (production):** [DEPLOY.md](DEPLOY.md) — Docker + PostgreSQL + автоматты HTTPS + күнделікті шифрланған резерв көшірме, бір командамен (`./deploy/install.sh`).

## WhatsApp (ресми Cloud API)

- **CRM ішіндегі чат:** «WhatsApp» бөлімі (кіріс жәшігі: барлығы / жауап күтуде / оқылмаған) және әр өтінім мен пациент картасында чат. Жеткізу статусы (✓ / ✓✓ / оқылды) көрінеді. Бас менеджер барлық чатты, менеджер тек өз өтінімдерін көреді.
- **Тегін 24 сағаттық терезе:** клиент соңғы рет жазғаннан кейін 24 сағат ішінде еркін жазуға болады (тегін). Терезе жабық болса, чатта тек «Үлгі жіберу (ақылы)» немесе «Телефоннан жазу» қалады.
- **Үнемді еске салу** (`REMINDER_HOURS`, әдепкі 24):
  - терезе ашық → тегін мәтін;
  - пациент «1» деп растап қойса → ақылы еске салу жіберілмейді;
  - тек расталмаған және терезе жабық болса → бір ақылы үлгі хабарлама;
  - 2 сағат бұрынғы еске салу — тек тегін болса.
  - Жазылған сәтте, егер клиент жақында жазған болса, тегін растау сұралады.
- Пациент «1» → «Расталды» + тегін автожауап; «2» → менеджерге «ауыстыру» тапсырмасы.
- Ақылы хабарлар саны: бас менеджер панелінде, «WhatsApp» бөлімінде және күнделікті Telegram есебінде.

**Қосу қадамдары:**
1. business.facebook.com → Meta Business аккаунты, компанияны растау.
2. developers.facebook.com → App құру → WhatsApp өнімі → нөмір қосу.
3. Webhook: `https://<домен>/api/webhooks/whatsapp`, Verify token = `WA_VERIFY_TOKEN`, `messages` жазылымы.
4. `.env`: `WA_TOKEN` (тұрақты System User токені), `WA_PHONE_NUMBER_ID`, `WA_VERIFY_TOKEN`, `META_APP_SECRET`.
5. WhatsApp Manager → Message templates → «Utility» санатында екі үлгі жасап, бекітуге жіберу:
   - `appointment_reminder` (kk): «Сәлеметсіз бе, {{1}}! Белес клиникасында {{2}} қабылдауыңыз бар ({{3}}). Растау үшін 1, ауыстыру үшін 2 жіберіңіз.»
   - `patient_followup` (kk): «Сәлеметсіз бе, {{1}}! Белес клиникасынан жазып тұрмыз. Ыңғайлы болса, осы чатқа жауап беріңіз.»

## Қауіпсіздік

- **Кіру:** bcrypt құпиясөздер (кемінде 8 таңба); 15 минутта 5 сәтсіз әрекеттен кейін логин бұғатталады (IP бойынша да шектеу бар).
- **Сессия:** httpOnly cookie, 12 сағат. Құпиясөз, рөл не белсенділік өзгерсе — сол қызметкердің барлық ашық сессиялары жабылады.
- **`AUTH_SECRET`** міндетті (≥32 таңба, `openssl rand -base64 48`). Продакшнда жоқ болса — жүйе іске қосылмайды.
- **Рөлдер:** менеджер тек өз өтінімдерін, дәрігер тек өз пациенттерін (карта, файлдар, кесте) көреді; баптау/журнал/экспорт — тек бас менеджер.
- **Файлдар:** тек JPG/PNG/WEBP/HEIC/PDF/DOC/DOCX/DICOM, 20 МБ дейін, ішкі мазмұны тексеріледі; дискіде кездейсоқ атпен сақталады; `nosniff` + sandbox CSP арқылы беріледі.
- **Webhook-тер:** WhatsApp/Instagram — Meta қолтаңбасы (`META_APP_SECRET`) тексеріледі; сайт формалары мен cron — құпия кілтпен.
- **Excel экспорты** формула шабуылынан қорғалған.
- **HTTP тақырыптары:** CSP, X-Frame-Options, nosniff, Referrer-Policy, HSTS (продакшн).
- **Журнал:** өзгерістер, медициналық картаны ашу, файл жүктеп алу, экспорт, сәтсіз логиндер.
- Продакшнда `npm run seed` бұғатталған (барлық деректерді өшіреді).

**Хостинг талаптары:** сервер Қазақстанда (ҚР «Дербес деректер туралы» заңы), тек HTTPS, дерекқор мен `uploads/` қалтасының күнделікті шифрланған резерв көшірмесі, пациенттен дербес деректерді өңдеуге келісім.
