# BELES · Касса

BELES медицина орталығына арналған касса: пациенттердің консультация және ем үшін төлемдері, ем бойынша қарыз, клиника расходы. **Интернетсіз** жұмыс істейтін iPhone қосымшасы (PWA).

Қосымша `docs/` папкасында. Деректер тек телефонның өзінде сақталады, ешқайда жіберілмейді.

Сілтеме: https://rusik979727-coder.github.io/rustam/

## iPhone-ға орнату

1. Safari-де сілтемені ашыңыз.
2. **Бөлісу** → **«Добавить на экран „Домой“»**.
3. Негізгі экраннан BELES белгішесі арқылы ашыңыз. Бір рет ашылғаннан кейін интернетсіз де жұмыс істейді.

## Сақтық көшірме

Аптасына бір рет **«Сақтық көшірме жасау»** батырмасын басып, `.json` файлды iCloud Drive-қа немесе WhatsApp-қа сақтаңыз. Жаңа телефонда **«Көшірмеден қалпына келтіру»** арқылы деректерді қайтарасыз.
