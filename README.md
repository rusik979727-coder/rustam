# Белес График

«БЕЛЕС ГРАФИК (приложение)» Google таблицасымен тікелей жұмыс істейтін жазылу приложениесі.
Таблица база болып қала береді: приложениеде жазылғанның бәрі бірден таблицада көрінеді,
ал таблицада қолмен өзгертілгені приложениеде 30 секунд ішінде жаңарады.

## Мүмкіндіктері

Приложение екі бөлек жазылудан тұрады, әрқайсысы таңертеңнен кешке дейін өз уақытымен:

- **Консультация** (A–H бағандары, 20 минуттық уақыттар). Бос уақытты басып пациентті жазасыз:
  аты, телефон, қызмет, қайдан келді, пікір. **Қай менеджер жазғаны міндетті**: таңдалмаса, жазба
  сақталмайды. Таңдау тізімдері таблицаның өз dropdown-тарынан оқылады.
  - **Келді / келмеді**: ✅ / ❌ бір басумен қойылады (`пд` бағаны).
  - **Көшіру**: жазбаны сол күннің немесе басқа күннің бос уақытына ауыстыру.
- **Ем** (J–L бағандары, 30 минуттық уақыттар, әр уақытта 3 орын). Емге кірген пациенттің аты мен
  ем түрі: **Физио**, **Плазма** немесе таблицада бұрын жазылған басқа түр (мысалы «Физио, системк»).
  Плазма кестеде бөлек түспен көрінеді.
- **Жаңа күн**: парағы жоқ күнге өткенде «Күн парағын жасау» батырмасы шығады. Парақ «Шаблон»
  парағынан, ол болмаса алдыңғы күннен көшіріледі: уақыттар, dropdown-тар, түстер, біріктірулер
  сақталады, пациенттер тазаланады.
- **Іздеу**: пациентті аты немесе телефоны бойынша барлық күндерден табу (8701… және +7701… бірдей).
- **Есеп**: апта, ай немесе кез келген кезең бойынша жазба саны, келу үлесі, қайдан келгені, кім жазғаны, ем түрлері.
- WhatsApp және қоңырау сілтемелері, «қазір» белгісі, телефонға бейімделген интерфейс.
- **Қауіпсіз жазу**: екі әкімші бір уақытқа қатар жазса, екіншісіне «басқа адам өзгертті» деген
  ескерту шығады, ешкімнің жазбасы үстінен жазылып кетпейді.

## Орнату (бір рет, шамамен 5 минут)

Компьютерден жасаңыз: телефондағы Google Sheets қосымшасында Apps Script мәзірі жоқ.

1. Таблицаны ашыңыз → **Расширения → Apps Script** (Кеңейтімдер → Apps Script).
   Скриптті дәл осы мәзірден ашу маңызды: сонда ол осы таблицаға байланады.
2. **`install/Code.gs`** мазмұнын көшіріп, редактордағы `Код.gs` ішіндегі бәрін өшіріп, орнына қойыңыз.
3. Сол жақтағы **Файлы** жанындағы **+ → HTML** басып, атын **`Index`** деп жазыңыз
   (бас әріппен, `.html`-сіз). Ішіндегі бәрін өшіріп, **`install/Index.html`** мазмұнын қойыңыз.
4. 💾 **Сохранить** басыңыз. Қаласаңыз, «Проект без названия» атауын «Белес График» деп өзгертіңіз.
5. **Начать развертывание → Новое развертывание → ⚙ → Веб-приложение** (Deploy → New deployment → Web app):
   - *Запуск от имени* (Execute as): **Пользователь, открывший приложение** (әр әкімші өз аккаунтымен жазады);
   - *Доступ* (Who has access): **Все, у кого есть аккаунт Google**.
6. Deploy басып, рұқсат беріңіз. Шыққан сілтемені (`https://script.google.com/macros/s/…/exec`)
   әкімшілерге жіберіңіз. Телефонда ашып, «Басты экранға қосу» арқылы қосымша сияқты қолдануға болады.

Приложениені тек таблицаны **өңдеуге рұқсаты бар** адамдар қолдана алады: рұқсат беру/алу таблицаның
«Бөлісу» батырмасы арқылы жасалады.

Кодты жаңартқаннан кейін: **Deploy → Manage deployments → ✎ → Version: New version → Deploy**
(сілтеме өзгермейді).

### clasp арқылы (бағдарламашыларға)

```bash
npm i -g @google/clasp && clasp login
cp .clasp.json.example .clasp.json   # scriptId: Apps Script → Жоба параметрлері → Script ID
npm run push
```

## Таблица құрылымы

Приложение әр күн парағын осы құрылым бойынша оқиды (қазіргі парақтар дәл осындай):

| Бағандар | Мазмұны |
| --- | --- |
| A | Консультация уақыты (9:00, 9:20 …) |
| B–H | ФИ пациента, номер, коммент, записал, источник, услуга, пд |
| J | Ем уақыты, әрқайсысы 3 жолға біріктірілген (3 орын) |
| K–L | Емге жазылған адамның аты, ем түрі (Физио, Плазма …) |

- Күн парақтарының атауы: `16.11.2026`, `18.11.26` сияқты. `10.112026` секілді қате жазылған атаулар да
  танылады. `5.11.2026 (копия)`, `Лист5` сияқты парақтарды приложение елемейді.
- Жаңа парақ үлгісін өзгерткіңіз келсе, бос **«Шаблон»** парағын жасаңыз: жаңа күндер содан көшіріледі.
- Тізімге жаңа әкімші, қызмет немесе дереккөз қосу үшін таблицадағы dropdown-ты
  (Деректер → Деректерді тексеру) өзгертсеңіз жеткілікті: приложение оны өзі оқиды.

## Әзірлеу

```bash
npm test      # 27 тест: парақ атаулары, құрылымды оқу, жазу, қақтығыс, көшіру, жаңа күн, іздеу, есеп
npm run bundle  # apps-script/ → install/ (2 файл); apps-script/ өзгерген сайын іске қосыңыз
npm run dev   # http://localhost:8080 — жалған таблицамен жергілікті алдын ала қарау
```

`tests/fake-gas.js` — SpreadsheetApp/LockService-тің жалған нұсқасы; `.gs` файлдары Node-та
Apps Script-тегідей ортақ global scope-пен жүктеледі. `tests/fixture.js` нақты парақтың
құрылымын қайталайды (аттар мен нөмірлер ойдан алынған).

```
apps-script/
  Code.gs        веб-приложение және API (getDay, saveAppointment, moveAppointment, createDay, …)
  Sheet.gs       парақ құрылымын оқу, іздеу, статистика (таза функциялар)
  Dates.gs       күн, уақыт, телефон (таза функциялар)
  Index.html     бет қаңқасы
  Styles.html    стильдер
  App.html       клиенттік JavaScript
tests/           Node тесттері
dev/server.js    жергілікті алдын ала қарау
```
