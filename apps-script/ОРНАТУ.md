# Белес қосымшасын орнату (бір рет, 10 минут, компьютерден)

Қосымша «Белес — Өтінімдер (CRM)» Google кестесімен жұмыс істейді: менеджер телефонда өтінім қосады не статусын ауыстырады, бәрі сол кестеге жазылады. Ақысы жоқ, сервер керек емес.

## 1. Менеджерлерді жазу
Кестедегі **«Баптаулар»** парағында:
- **A бағаны:** менеджерлердің аты («Менеджер 1» орнына);
- **F бағаны:** әр менеджердің Gmail поштасы, сол жолға.

Кестені әр менеджермен бөлісіңіз: **«Настройки доступа» → email → «Редактор»**. Бас менеджер — кесте иесі (сіз), сіз барлық өтінімді көресіз.

## 2. Кодты қою
1. Кестені **компьютерде** ашыңыз → мәзірден **Расширения → Apps Script**.
2. Ашылған терезеде сол жақта **«Код.gs»** файлы тұр. Ішіндегі мәтінді түгел өшіріп (Ctrl+A, Delete), Google Drive-тағы **«Белес қосымша — Code.gs»** құжатының мәтінін түгел көшіріп қойыңыз (Ctrl+A, Ctrl+C → Ctrl+V).
3. «Файлы» жанындағы **«+» → «HTML»** басыңыз, атауын **Index** деп жазыңыз (`.html` жазбаңыз).
4. Ішіндегі мәтінді өшіріп, **«Белес қосымша — Index.html»** құжатының мәтінін көшіріп қойыңыз.
5. **Ctrl+S** (сақтау).

## 3. Іске қосу (Развернуть)
1. Оң жақ жоғарыда **«Начать развертывание» → «Новое развертывание»**.
2. Шестерня белгісі → **«Веб-приложение»**.
3. Баптаулар:
   - **Запуск от имени:** «Пользователь, открывший веб-приложение»
   - **Доступ:** «Все, у кого есть аккаунт Google»
4. **«Начать развертывание»** → **«Предоставить доступ»** → өз аккаунтыңызды таңдаңыз.
5. «Google не проверил это приложение» деген ескерту шығады. Бұл қалыпты: қосымшаны өзіңіз жасадыңыз. **«Дополнительные настройки» → «Перейти на страницу…» → «Разрешить»**.
6. **«URL веб-приложения»** сілтемесін көшіріп алыңыз. Қосымшаның адресі — осы.

> Неге «Пользователь, открывший…»: әр адам өз Google аккаунтымен кіреді. Кестеге рұқсаты жоқ адам сілтемені тапса да, ештеңе көре алмайды.

## 4. Телефонға орнату
1. Сілтемені менеджерлерге WhatsApp арқылы жіберіңіз.
2. iPhone: Safari-де ашыңыз → Google аккаунтымен кіріңіз → бірінші рет «Разрешить» → төмендегі **«Поделиться» → «На экран Домой»**. Экранда қосымша белгішесі пайда болады.
3. Android: Chrome-да ашыңыз → ⋮ → **«Добавить на главный экран»**.

## Қосымшада не бар
- **Нөмір бойынша іздеу:** екі бетте де жоғарыда. Нөмірді кез келген түрде жазуға болады (8 701…, +7 701…, не соңғы цифрлары), «Іздеу» батырмасы.
- **Әр нөмірдің астында:** лид қашан келгені (күні мен сағаты), шағымы, дереккөзі, соңғы пікір.
- **Бүгін:** уақыты өтіп кеткен қоңыраулар (бірінші), бүгінгі конс, жаңа лидтер.
- **Барлығы:** түскен күні бойынша бөлінген («Бүгін, 26.11: 7 лид», «Кеше, 25.11: 12 лид»…), «Бүгін түскендер» сүзгісі, статус сүзгісі; бас менеджерде менеджер бойынша сүзгі.
- Әр нөмірде: **Қоңырау**, **WhatsApp**, **Пікір**, **Статус** батырмалары.
- **Пікір:** бұрынғы пікірлер көрінеді, жаңасына күні мен менеджер аты өзі жазылады.
- **Статус:** «Конс» → күні, «Емге төледі» → сомасы, «Отказ» → себебі. «Не отвечает» → 2 сағаттан кейін қайта қоңырау өзі қойылады.
- **Жаңа өтінім:** тек нөмір жеткілікті (аты міндетті емес), келген уақыты өзі жазылады. Нөмір бұрыннан бар болса, қайталап қоспай, сол нөмірді көрсетеді.

## Кодты жаңарту (кейін өзгеріс болса)
Apps Script → кодты ауыстырып сақтау → **«Развертывание» → «Управление развертываниями»** → қарындаш → **«Версия: Новая версия»** → «Развернуть». Сілтеме өзгермейді.

## Ақаулар
- **«Кіруге рұқсат жоқ»** — менеджердің email-ы «Баптаулар» F бағанында жоқ не қате жазылған.
- **«Кесте өзгерген…»** — біреу кестені сұрыптаған. ⟳ «Жаңарту» басып, қайталаңыз.
- Бос ақ бет — Google аккаунтқа кірмеген. Safari-де google.com ашып, кіріп, қайта көріңіз.
