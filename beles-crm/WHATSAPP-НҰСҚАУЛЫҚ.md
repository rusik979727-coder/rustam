# WhatsApp → Белес CRM: лидтерді автоматты түрде енгізу

Клиент WhatsApp-қа жазғанда, оның нөмірі CRM-нің **«Жаңа»** кезеңіне өзі түседі.
Жүйе тегін және Meta-ның ресми жолымен жұмыс істейді:

```
Клиент WhatsApp-қа жазады → Meta (WhatsApp Cloud API) → Cloudflare көпірі → Белес CRM
```

**Не түседі:** нөмір, WhatsApp-тағы аты, бірінші хабарлама және жарнама.
Клиент «WhatsApp-қа жазу» жарнамасынан келсе, **жарнаманың атауы** «Жарнама» өрісіне өзі жазылады.

**Қосымша мүмкіндіктер:**
- Бар нөмір қайта жазса, жаңа лид жасалмайды: карточканың тарихына «Қайта жазды» деп қосылады.
- Бұрын **Отказ** немесе **Не пришёл** кезеңінде тұрған адам қайта жазса, нөмір өзі **Жаңа** кезеңіне қайтарылады.
- Жаңа нөмірлер «Баптаулар» парағындағы менеджерлерге **кезекпен** бөлінеді.

Жүйе тек **кіріс** хабарламаларды қабылдайды, ешкімге өзі хабарлама жібермейді.

Барлығы шамамен **2–3 сағат** алады. Бір рет жасалады.

---

## 0. Алдымен: қауіпсіздік

**Google**, **Facebook** және **Cloudflare** аккаунттарының үшеуінде де **екі сатылы растауды (2FA)** қосыңыз.

## 1. CRM-ді жаңарту

1. «Белес CRM» таблицасында **Расширения → Apps Script** ашыңыз.
2. **Code.gs** мәтінін осы бумадағы жаңа **Code.gs** мәтінімен ауыстырып, **Сохранить** басыңыз.
3. **Развернуть → Управление развертываниями → (қарындаш) → Версия: Новая версия → Развернуть** таңдаңыз.
4. Таблицада **Белес CRM → Сілтемелерді көрсету / жасау** басыңыз.
5. «Сілтемелер» парағының соңғы жолындағы **«Автоматтандыру (webhook)»** сілтемесін көшіріп алыңыз. Бұдан әрі оны **CRM сілтемесі** деп атаймыз.

## 2. Meta-да WhatsApp API ашу

1. **business.facebook.com** ашыңыз. Бизнес портфоліо (Business portfolio) жоқ болса, жасаңыз.
2. **developers.facebook.com → My Apps → Create App** таңдаңыз:
   - қолдану мақсаты (use case): **Other**, ал түрі: **Business**;
   - аты: `Белес CRM`;
   - бизнес портфоліоңызды таңдаңыз.
3. Приложениенің бетінде **WhatsApp** өнімін тауып, **Set up** басыңыз.
4. **Нөмірді қосу (ең маңызды қадам):** **WhatsApp → API Setup → Add phone number** таңдаңыз.
   - Meta **«бар WhatsApp Business қосымшасын қосу»** (coexistence) деген мүмкіндік ұсынса, соны таңдаңыз. Сонда телефондағы WhatsApp Business жұмыс істей береді. Әдетте WhatsApp Business қосымшасында **Баптаулар → Бизнес платформа** арқылы QR сканерлеу сұралады.
   - ⚠️ Meta нөмірді **WhatsApp қосымшасынан өшіруді** талап етсе, **тоқтаңыз**. Нөмірді өшірмеңіз де, маған жазыңыз. Бірге жаңа нөмір алу немесе басқа жолды шешеміз.
5. **App secret кілтін алу:** **App settings → Basic → App secret → Show** басып, кілтті көшіріп алыңыз. Бұл — **APP_SECRET**. Оны ешкімге бермеңіз.

## 3. Cloudflare көпірін орнату

1. **dash.cloudflare.com** сайтында тегін тіркеліңіз.
2. **Workers & Pages → Create → Create Worker** таңдаңыз. Аты: `beles-wa`. **Deploy** басыңыз.
3. **Edit code** басып, ішіндегінің бәрін өшіріңіз. Осы бумадағы **whatsapp-worker.js** мәтінін түгел көшіріп қойып, **Deploy** басыңыз.
4. Worker-дің **Settings → Variables and Secrets → Add** бөліміне үш айнымалы қосыңыз. Үшеуінің де түрі **Secret** болсын:

   | Аты | Мәні |
   |---|---|
   | `APP_SECRET` | 2-бөлімнің 5-қадамындағы Meta App secret |
   | `VERIFY_TOKEN` | Өзіңіз ойлап табатын ұзын сөз, мысалы `beles-wa-7Kq92xLm`. Оны жазып қойыңыз |
   | `CRM_HOOK` | 1-бөлімнің 5-қадамындағы CRM сілтемесі (толық, `?token=…` бөлігімен қоса) |

5. **Deploy** басыңыз.
6. Worker сілтемесін көшіріп алыңыз, ол мынадай болады: `https://beles-wa.<атыңыз>.workers.dev`. Оны браузерде ашқанда **«Белес WhatsApp көпірі жұмыс істеп тұр.»** деген жазу шығуы керек.

## 4. Meta-ны көпірге қосу

1. Meta приложениесінде **WhatsApp → Configuration → Webhook → Edit** таңдаңыз:
   - **Callback URL:** Worker сілтемесі;
   - **Verify token:** `VERIFY_TOKEN`-ге жазған сөзіңіз (дәл сондай болуы керек).
   - **Verify and save** басыңыз.
2. **Webhook fields → Manage** басып, **messages** жолына жазылыңыз (Subscribe).
3. **Приложениені Live режиміне ауыстырыңыз:** жоғарыдағы **App Mode** ауыстырғышын басасыз. Development режимінде хабарламалар келмейді.
   - Meta **Privacy Policy URL** сұрайды. Сайтыңызда құпиялылық саясаты беті болса, соны қойыңыз. Болмаса, айтыңыз, қарапайым бетін жасап беремін.

## 5. Тексеру

1. **Басқа телефоннан** нөміріңізге WhatsApp-та «Сәлем, тест» деп жазыңыз.
2. 5–10 секундтан кейін CRM-де **Жаңарту** басыңыз. Нөмір **Жаңа** кезеңінде тұруы керек, ал оның тарихында «Лид автоматты түрде түсті: Сәлем, тест» деп жазылады.
3. Сол телефоннан тағы бір хабарлама жазыңыз. Жаңа лид пайда болмауы керек, тарихқа «Қайта жазды» деп қосылуы керек.

## Ақаулар

| Белгі | Себебі мен шешімі |
|---|---|
| Meta-да «Verify and save» өтпейді | `VERIFY_TOKEN` екі жерде бірдей емес, не Worker-ге **Deploy** басылмаған |
| Хабарламалар CRM-ге түспейді | 1) **messages** жолына жазылмағансыз; 2) приложение **Live** емес; 3) `CRM_HOOK` толық емес (`?token=` жоқ) |
| Не болып жатқанын көру | Cloudflare → **beles-wa → Logs → Begin log stream**, содан кейін тест хабарлама жіберіңіз |
| Логта **401** шығады | `APP_SECRET` дұрыс емес. Meta-дан қайта көшіріп қойыңыз |
| CRM сілтемесі ауыстырылды | Cloudflare-де `CRM_HOOK` мәнін жаңа сілтемеге ауыстырыңыз |

## Клиенттерге жауап беру

- **Coexistence қосылса:** бұрынғыдай телефондағы WhatsApp Business-тен жауап бересіз. CRM-дегі **WA** батырмасы сол чатты ашады.
- **Нөмір тек API-да болса:** жауапты **Meta Business Suite → Inbox** арқылы бересіз. Қаласаңыз, кейін жауап беруді CRM-нің ішіне де қосуға болады.

## Қауіпсіздік

- **Жалған хабарламадан қорғаныс:** көпір әр хабарламаның шынымен Meta-дан келгенін тексереді (`APP_SECRET` арқылы). Жалған сұраныстар қабылданбайды.
- **CRM-ге жазудың құпия кілті:** CRM тек құпия кілті бар сұранысты қабылдайды. Кілт тарап кетсе: **Белес CRM → Автоматтандыру сілтемесін ауыстыру** таңдап, Cloudflare-дегі `CRM_HOOK` мәнін жаңартасыз.
- **Кілттердің сақталуы:** барлық кілт Cloudflare-дің жабық Secret баптауларында тұрады, кодта жоқ.
