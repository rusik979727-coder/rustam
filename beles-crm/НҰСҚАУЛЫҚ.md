# Белес CRM — колл-орталыққа арналған лид базасы

Бұл **бөлек** приложение, оның өз Google Таблицасы бар. Негізгі «Белес маркетинг» приложениесі өзгеріссіз қалады.

**Не істейді:**
- Әр лидтің **жеке карточкасы** болады: аты, телефоны, қай жарнамадан келгені, қызмет, статус, келесі байланыс уақыты, жазылу уақыты, ескерту және **барлық өзгерістің тарихы**.
- Карточкадан бір басумен **WhatsApp ашылады** немесе **қоңырау шалынады**.
- **«Бүгін хабарласу керек»** тізімі: қайта қоңырау шалатын уақыты келген лидтер жоғарыда тұрады.
- **Бүгінгі есеп:** колл-орталықтың күндік цифрлары негізгі таблицадағы атаулармен шығады (Кол-во новых лидов, Запись, Недозвон, В работе, Отказ, Конверсия). Оларды негізгі приложениенің «Күнді енгізу» бөліміне көшіресіз.
- **Талдау:** воронка, жарнамалар бойынша және менеджерлер бойынша есеп.
- **Әр менеджер тек өз лидтерін** көреді, ал бастық бәрін көреді және лидті басқа менеджерге бере алады.
- **Автоматтандыруға дайын:** WhatsApp сервисін қоссаңыз, лидтер өздігінен түседі (төменде «Автоматтандыру» бөлімін қараңыз).

Статустар: **Жаңа → Жауап бермеді / Ойланып жүр → Жазылды → Келді / Келмеді → Сатып алды**, немесе **Бас тартты**.

---

## 1-қадам. Жаңа Google Таблица ашу

1. drive.google.com ашып, **Создать → Google Таблицы → Пустая таблица** таңдаңыз.
2. Оның атын **«Белес CRM»** деп қойыңыз.
3. Таблицаны **ешкіммен бөліспеңіз.** Менеджерлер оған таблица арқылы емес, сілтеме арқылы кіреді.

## 2-қадам. Кодты қою

1. Жаңа таблицада **Расширения → Apps Script** таңдаңыз.
2. **Code.gs** ішіндегінің бәрін өшіріп, осы бумадағы **Code.gs** мәтінін көшіріп қойыңыз.
3. **«+» → HTML** басып, файлдың атын `Index` деп қойыңыз. Ішіндегісін өшіріп, **Index.html** мәтінін көшіріп қойыңыз.
4. **Сохранить** басыңыз.

## 3-қадам. Жариялау

1. **Развернуть → Новое развертывание** таңдаңыз. «Тип» жанындағы тісті доңғалақты басып, **Веб-приложение** таңдаңыз.
2. Баптауларды былай қойыңыз:
   - **Запуск от имени:** **Я**
   - **У кого есть доступ:** **Все**
3. **Развернуть** басыңыз да, рұқсат беріңіз: **Предоставить доступ** → аккаунт → **Дополнительные настройки** → **Перейти на страницу (небезопасно)** → **Разрешить**.

## 4-қадам. Сілтемелерді алу

1. Таблицаны қайта жүктеңіз (F5). Жоғарыда **Белес CRM** мәзірі пайда болады.
2. **Белес CRM → Сілтемелерді көрсету / жасау** таңдаңыз.
3. Таблицада үш парақ пайда болады:
   - **Лидтер**: барлық лидтер. Оны қолмен өзгертпеңіз, бәрі приложение арқылы жасалады;
   - **Баптаулар**: жарнамалар, қызметтер және менеджерлер тізімі;
   - **Сілтемелер**: әр менеджердің сілтемесі және автоматтандыру сілтемесі.
4. **«Бастық»** сілтемесі — сіздікі. **«Менеджер 2»** сілтемесін екінші менеджерге бересіз.

## Баптаулар

**«Баптаулар»** парағында тізімдерді өзгертесіз:
- **Жарнамалар**: Instagram, Facebook, WhatsApp, TikTok… Мұнда әр жарнамалық науқанның атын жазуға болады, мысалы «Акция қараша». Таргетологқа қай жарнама сатып алушы әкелетінін көрсететін есеп осыған сүйенеді.
- **Қызметтер**: сіз сататын қызметтер мен тауарлар.
- **Менеджерлер**: әр адамның аты. «Бастық» деген жолды өшірмеңіз.

Жаңа менеджер келгенде, оның атын «Менеджерлер» бағанына жазасыз да, **Белес CRM → Сілтемелерді көрсету / жасау** басасыз. Оған жеке сілтеме жасалады.

Менеджер жұмыстан кетсе: **Белес CRM → Бір менеджердің сілтемесін ауыстыру** таңдап, атын жазасыз. Ескі сілтеме бірден жұмыс істемей қалады. Оның лидтерін бастық карточкада басқа менеджерге береді.

## Күнделікті жұмыс (менеджерге)

1. WhatsApp-қа жаңа адам жазды → CRM-де **«+ Жаңа лид»** басасыз → телефон, аты, жарнама → **Сақтау**.
2. Хабарласқан соң статусты белгілейсіз:
   - көтермеді → **Жауап бермеді**, сосын «Ертең 10:00» басасыз;
   - ойланып жүр → **Ойланып жүр**, келесі байланыс уақытын қоясыз;
   - жазылды → **Жазылды**, жазылу уақытын қоясыз.
3. Әр сөйлесуден кейін **«Пікір қосу»** өрісіне қысқаша жазып қойыңыз, мысалы «бағасын сұрады». Бәрі тарихта сақталады.
4. Күн соңында **Бүгінгі есеп → Көшіру** басып, цифрларды негізгі приложениеге енгізесіз.

Телефонда ыңғайлы болу үшін сілтемені **«На экран Домой»** арқылы иконка етіп қойыңыз.

## Автоматтандыру (кейін)

CRM-нің **кіріс сілтемесі (webhook)** бар, ол «Сілтемелер» парағының соңғы жолында тұр. Қандай да бір сервис осы сілтемеге мынадай сұраныс жіберсе, лид **өзі пайда болады**:

```
POST <сілтеме>
Content-Type: application/json

{ "phone": "+77011234567", "name": "Айгерім", "source": "Instagram", "text": "Сәлем! Акция туралы" }
```

- Жаңа нөмір келсе, «Жаңа» статусымен жаңа лид жасалады. Ол «Менеджерлер» тізіміндегі адамдарға кезекпен бөлінеді.
- Бар нөмір қайта жазса, жаңа лид жасалмайды: карточканың тарихына «Қайта жазды» деп жазылады.

**Қалай қосуға болады:**
- **Wazzup, ChatApp, Umnico** сияқты сервистер WhatsApp-қа жаңа хабарлама келгенде webhook жібере алады. Олардың хабарлама пішімі бөлек болуы мүмкін, сондықтан қай сервисті таңдағаныңызды айтсаңыз, кодты соған бейімдеп беремін.
- **Make.com / Zapier** арқылы да қосуға болады: «WhatsApp → HTTP request» сценарийін құрып, жоғарыдағы JSON-ды жібересіз.
- Кейін тікелей **WhatsApp Business API (Meta)** арқылы да қосуға болады. Сонда «WhatsApp-қа жазу» жарнамасынан келген адамның қай жарнамадан келгені де автоматты түрде жазылады.

⚠️ Webhook сілтемесін тек сервиске беріңіз. Ол таралып кетсе, **Белес CRM → Автоматтандыру сілтемесін ауыстыру** басыңыз.

## Кодты жаңарту

Apps Script-те файлдарды ауыстырып, **Сохранить** басыңыз. Содан кейін **Развернуть → Управление развертываниями → (қарындаш) → Версия: Новая версия → Развернуть** таңдаңыз. Сілтемелер өзгермейді.
