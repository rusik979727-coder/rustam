# Шығын дәптері

Күнделікті шығындарды есептеуге арналған қосымша (қазақ тілінде, ₸).

- `index.html` — қосымшаның өзі (claude.ai-да жарияланған нұсқа да осы).
- `offline/` — телефонға/компьютерге орнатылатын, интернетсіз істейтін нұсқа.
- `build-offline.js` — `index.html` өзгерсе, офлайн нұсқаны қайта жинау: `node expenses/build-offline.js`

## Офлайн нұсқаны ашу

**GitHub Pages арқылы (телефонға ең ыңғайлысы):**
1. GitHub → репо → Settings → Pages.
2. Source: *Deploy from a branch*, тармақты таңдап (`main` немесе осы тармақ), папка `/ (root)` → Save.
3. Бірнеше минуттан кейін ашыңыз: `https://<username>.github.io/rustam/expenses/offline/`
4. Телефонда: Safari → «Бөлісу» → «Басты экранға қосу» (iPhone) немесе Chrome → ⋮ → «Қолданбаны орнату» (Android).

Бір рет интернетпен ашқаннан кейін қосымша интернетсіз де ашылады.

**Компьютерде файлмен:** `offline/index.html` файлын браузерде ашсаңыз болды. Интернетсіз де жұмыс істейді.

## Деректер

Офлайн нұсқа деректерді сол құрылғының браузерінде сақтайды. Құрылғы ауыстырғанда немесе claude.ai нұсқасынан көшіргенде «Резервтік көшірме» бөліміндегі «Файлға сақтау» / «Файлдан жүктеу» батырмаларын қолданыңыз. Бұрыннан бар жазбалар қайталанбайды.
