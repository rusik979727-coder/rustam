## Ережелер
- Қазақша мәтінге: **Montserrat**, **NobelKaz**, **Trajan Pro 3**, **KZ Piedra**, **Sports World**.
- **NobelWGL** және **NAMU** — тек латын/орыс мәтініне (қазақ әріптері жоқ).
- **Century Gothic Paneuropean** — «Ұ/ұ» жоқ; бұл әріп кездессе, басқа шрифт қолданыңыз.
- Montserrat-та тек 100, 500i, 700, 800i, 900i бар — басқа салмақтар жалған (синтетикалық) болады.
