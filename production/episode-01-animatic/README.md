# 1-серия · 3D аниматик

«ОМЫРТҚА ӘЛЕМІ» 1-сериясының («Омыртқа өзін таныстырады») **процедуралық 3D аниматигі**: 60 сек, 1080×1920 (9:16), 24 fps, қазақша субтитр, синтезделген музыка мен дыбыс эффектілері.

**Дайын видео:** [`out/episode-01-animatic.mp4`](out/episode-01-animatic.mp4)

> Бұл — финалды Pixar-рендер емес, **жұмыс нұсқасы (animatic / previz)**: тайминг, камера, кейіпкерлердің эмоциясы, түс драматургиясы, субтитр мен дыбыс сценарийге сәйкес тексеріледі. Финалды кадрлар `series/inside-the-spine/episode-01/02-ai-image-prompts.md` және `03-ai-video-prompts.md` арқылы AI-генераторда жасалып, осы аниматиктің таймингіне қойылады.

**Дауыс жоқ** — диалог тек субтитрмен. Дауысты (`04-voiceover.md`) жазып алған соң, монтажда `out/audio.wav` үстіне қосыңыз.

## Файлдар

- `timeline.js` — барлық тайм-код: камера кілттері, кейіпкерлердің эмоция/поза трактары, субтитрлер.
- `scene.js` — Three.js сахналары (Тірек қаласы, Тірек, Жұмсақ, сыртқы көше, дискінің ішкі әлемі, арқа шейдері) және пост-өңдеу (bloom, violet–gold / суық грейд, виньетка, grain).
- `scene.html` — 1080×1920 «сахна» + субтитр/титр қабаты (Inter қарпі).
- `render.mjs` — Playwright + Chromium арқылы кадр-кадрмен рендер.
- `audio.py` — numpy-мен музыка және SFX синтезі (лейтмотив D–F#–A–D′, пиццикато/домбыра шертпесі, маримба, хор, фортепиано, жүрек соғысы, «БОИНГ», «ҚЫРТ», BRAAM…).
- `build.sh` — бәрін жинайды → `out/episode-01-animatic.mp4`.
- `out/keyframes/` — негізгі сәттердің кадрлары.

## Қайта жинау

```bash
cd production/episode-01-animatic
./build.sh                         # толық жинау (~10 мин, 4 ядро)
node render.mjs --times 8,25,42    # тек жеке кадрларды preview/ ішіне
```

Уақытты, камераны немесе эмоцияны өзгерту үшін тек `timeline.js`-ті түзетіп, `frames/` папкасын өшіріп, `./build.sh` іске қосыңыз.
